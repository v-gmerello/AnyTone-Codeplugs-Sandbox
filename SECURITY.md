# Security Policy

## Supported Versions

The project is in pre-release development and has no supported production
version yet.

| Version | Supported |
| --- | --- |
| `main` pre-release scaffold | Best effort |
| Published releases | None yet |

Supported versions will be listed explicitly before the first public release.

## Reporting a Vulnerability

Do not disclose vulnerabilities, credentials, personal codeplugs, DMR IDs,
private frequencies, or radio recovery data in a public issue.

Use GitHub private vulnerability reporting for this repository when available.
